# UI & theming invariants (Source/UI/)

One rule per bullet; mechanism and history live in the linked docs.

- **No unconditional per-tick repaint**: card images are cached, timers are gated, every animation is an `AnimationDriver`; only the permitted exceptions may repaint per tick. → [rendering](../../docs/layout/rendering.md) · [animation](../../docs/layout/animation.md#the-time-bounded-animation-rule)
- **A change that moves a cable end without moving a card, knob or edge calls `GraphEditor::repaintCanvas()`** (`notifyModuleContentChanged()` from a card). → [rendering](../../docs/layout/rendering.md#per-frame-work-does-not-grow-with-the-patch)
- **A cable is not a graph edge**: enumerate via `GraphEditor::buildVisibleCables()`, never `AudioProcessorGraph::Connection`; colour only via `synth::ui::resolveCableColour`. → [cables](../../docs/layout/cables.md)
- **Themes never swap the font family**; they differ by colour, treatment and glow. → [theming](../../docs/layout/theming.md)
- **Every search box uses `Layout/SearchMatch.h`** (`searchMatches`/`searchScore`/`drawSearchHighlightedText`); never `containsIgnoreCase`. → [chrome](../../docs/layout/chrome.md#shared-search)
- **No high-frequency `writeToLog`** (per-sample, frame, parameter or connection). → [chat-component](../../docs/ai/chat-component.md#logging-rules)
- **A rebuild that removes a live drag's component calls `GraphEditor::cancelLiveDragGestures()`.** → [selection](../../docs/layout/selection.md#drag-in-progress-flags-and-their-reset-sites)
- **`GraphEditor` is a thin owner**: new API for smart connections, macros or drag-drop goes on `SmartConnectionEngine`/`MacroGroupController`/`GraphDragDropController` via their getters, never a `GraphEditor` forwarder. → [graph-editor](../../docs/architecture/graph-editor.md#new-api-goes-on-the-collaborator-not-grapheditor)
- **A track header never sees the graph**: its mixer-channel data comes only through `TrackChannelLinkSurface` (`TrackHeaderHost::getChannelLinkSurface()`). → [mixer](../../docs/mixer/mixer.md#channels-follow-audio-not-tracks) · [tracks](../../docs/timeline/tracks.md#the-channel-chip)
- **A menu a background thread can change resolves clicks against its build-time snapshot** (`instrumentPluginMenuSnapshot_`). → [add-track](../../docs/timeline/add-track.md#menu-options-resolve-against-a-build-time-snapshot)
- **Any mixer UI holding a parameter/module pointer unbinds via `MixerPanelComponent::unbindAllColumns()`**; a new bound control joins `MixerColumnComponent::unbindFromGraph()` (and `bindsAnyOf`). → [sends-and-buses](../../docs/mixer/sends-and-buses.md) · [panel](../../docs/mixer/panel.md#a-rebuild-keeps-the-columns-that-did-not-change)
- **A single `removeNode()` frees the processor at once**: a UI object holding a pointer into it needs a pre-removal unbind (`MixerInsertList::onBeforeNodeRemoved`) or a liveness check. → [panel](../../docs/mixer/panel.md#the-eq-curve-thumbnail)
- **A mixer list never outlives a rebuild it started**: hold `rebuildIfStale()`/`rebuildWhenShown()` around a drag-reorder commit; `onMutated()` is the one rebuild. → [sends-and-buses](../../docs/mixer/sends-and-buses.md#reordering-sends) · [row-motion](../../docs/mixer/row-motion.md)
- **A tab's side pane is a `SidePane` child of the panel** (never of `BottomDockComponent`), persisted per tab; its content holds no state of its own. → [side-pane](../../docs/layout/side-pane.md) · [panel](../../docs/mixer/panel.md#side-pane-zones-and-visibility)
- **An in-place label edit is a `synth::ui::NonModalLabel`**, never a plain `juce::Label` (modal breaks VoiceOver). → [chrome](../../docs/layout/chrome.md#inline-label-editors-and-accessibility)
- **No file over 1,000 lines; `Source/UI/` holds only area directories**: a new file goes in its area, never back here. → [file-size-guard](../../docs/development/file-size-guard.md#how-to-split-an-over-cap-file)
- **A card's own visualizer follows the existing gated 15 Hz `ModuleComponent` timer**, never a new `Timer`; grow `layoutDefaultContent` by extracting a named step. → [visualizers](../../docs/layout/visualizers.md) · [lfo](../../docs/modules/lfo.md)
- **A built-in card's body is built and laid out by its `CardBody`**: layouts choose widget and place, never a binding; measure == apply; no second gesture copy. → [module-card-layout](../../docs/layout/module-card-layout.md#rendering) · [module-card](../../docs/layout/module-card.md#the-more-row)
- **Every learnable card control goes through `ModuleComponent::registerMidiLearnable`** (hosted: `registerHostedMidiLearnable`), using the shared `MidiRemote/MidiLearnMenu.h` helpers; Pick-on-canvas is entered from the MIDI Remote panel only. → [midi-remote-ui](../../docs/control/midi-remote-ui.md#right-click-midi-learn--coverage)
- **Drop a hosted learnable-registry entry before the card rebuild**: `clearHosted()` from `unbindHostedPluginCard()`. → [plugin-card-layout](../../docs/control/plugin-card-layout.md#as-built-fro137)
- **A split class's header declares; its units document**: caller-facing facts in the header, maintainer rationale beside the out-of-line definition. → [header-comment-guard](../../docs/development/header-comment-guard.md)
- **Hosted-parameter UI binds per parameter and hops threads via `AsyncUpdater`** (never touch a widget in `parameterValueChanged`); unbind on `hostedInstanceGone`. → [plugin-card-layout](../../docs/control/plugin-card-layout.md#instance-lifetime-and-unbinding)
- **"Add by moving a control" listens on every parameter and hops threads the same way**; `onParameterTouched` fires only from `handleAsyncUpdate()`. → [plugin-card-layout](../../docs/control/plugin-card-layout.md#choosing-knobs-as-built-fro132)
- **The Cmd-hold shortcut hint overlay costs nothing at rest**: no free-running timer, no clicks, never moves a component; buttons opt in by action via `MainComponentShortcutHints.cpp` / `getShortcutHintTargets()`. → [shortcuts](../../docs/control/shortcuts.md#shortcut-hints)
- **A Preferences row lives in its category's `layout*Groups`**, never in `layoutContent`. → [settings-preferences](../../docs/layout/settings-preferences.md)
- **Motion follows the Motion rules; reorderable lists use `Layout/ReorderDrag/` (`ReorderDragAnimator`)**; added tracks wrap in `MainComponent::TrackGrowInScope`. → [animation](../../docs/layout/animation.md#motion-rules)
- **Every app-decided popup close goes through `PopupMotion::dismiss*`/`closeHostingWindow`**, never `exitModalState(0)`/`closeButtonPressed()`/`CallOutBox::dismiss()`. → [animation](../../docs/layout/animation.md#popup-windows)
- **Anything that grows a macro hull or card calls `makeRoomFor` inside its undo record**; hidden collapsed members are never layout units. → [layout](../../docs/layout/layout.md#making-room-when-something-grows)
- **Every drag-and-drop uses the shared `Layout/DragCursor.h`** (`followDragCursor`/`endDragCursor`); never set drag cursors by hand. → [animation](../../docs/layout/animation.md#drag-and-drop-cursor)
- **Never write Audio Output / Rec Tap / Master x directly**: `GraphEditor::reflowOutputDock()` derives it. → [layout](../../docs/layout/layout.md#output-dock)
- **A user Poly-pill click goes through `PolyChainController` as ONE undo step; programmatic sets never propagate.** → [modulation](../../docs/modules/modulation.md#the-poly-toggle)
- **Auto-arrange is a pure function of sizes, topology and track order, ONE undo step**: `computeHierarchicalArrange`, geometry written synchronously. → [layout](../../docs/layout/layout.md#auto-arrange)
- **Nothing sits left of or above (0,0), and the canvas never clamps to a fixed size**: use `clampDragDeltaToCanvas` and `slidePatchForEdgeDrop`. → [layout](../../docs/layout/layout.md#canvas-frame)
- **Canvas-initiated card moves run in one `CardGlideAnimator::Scope`**; geometry is final at once, never animate bounds. → [layout](../../docs/layout/layout.md#making-room-when-something-grows)
- **Card outlines take `synth::ui::cardBodyRect` and `metrics.cornerRadius`**, never literals. → [insert-motion](../../docs/layout/insert-motion.md)
- **TimelinePanelComponent asks `clipEditorOpen()` whether a clip editor (piano roll or drum machine) covers the lanes**, never `pianoRoll_.isOpen()` alone; a new editor joins that predicate and the playhead's local client. → [drum-machine](../../docs/timeline/drum-machine.md#how-it-is-hosted)
- **Every new control: keyboard path, `paintFocusRing`, `setTitle` name, tooltip; dialogs Tab in visual order and close on Escape.** → [accessibility](../../docs/development/accessibility.md)
- **One shared component per control kind** (`AppLookAndFeel`, `IconLibrary`, `Layout/` widgets); colours from theme tokens (`themeOf(component)`), never literals. → [theming](../../docs/layout/theming.md#themed-widgets)
- **UI text is never all caps** (`scripts/check-ui-caps.sh`); list arrow keys come from `synth::ui::ArrowKeyNavigation`. → [accessibility](../../docs/development/accessibility.md#arrow-keys-in-lists-of-controls)
- **A note-length choice uses `Layout/NoteLengthMenu` (`NoteLengthBox`), never a plain `juce::ComboBox`.** → [note-length-menu](../../docs/layout/note-length-menu.md)
- **A "don't ask again" question is `showConfirmDontAsk`** (`Chrome/ConfirmDontAskDialog.h`). → [animation](../../docs/layout/animation.md#popup-windows) · [tracks](../../docs/timeline/tracks.md#row-context-menu)
- **A jack click opens the port panel via `PortPanelController`** (`GraphEditor::getPortPanel()`), never a per-card popup. → [cables](../../docs/layout/cables.md#port-connections-panel)
- **A canvas edit changing the graph more than once uses `UpdateKind::none` inside one `synth::GraphRebuildScope`.** → [graph-queries](../../docs/architecture/graph-queries.md#one-audio-graph-rebuild-per-edit)
- **The Custom shape-list section is `MorphShapesCard`**, a collaborator reached via `getMorphCard()`, not `ModuleComponent` members. → [custom-filter](../../docs/modules/custom-filter.md#card) · [lfo](../../docs/modules/lfo.md)
