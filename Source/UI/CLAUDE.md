# UI & theming invariants (Source/UI/)

Mechanism and history live in the linked docs.

- **No unconditional per-tick repaint** — `ModuleComponent` is buffered-to-image with a gated 15 Hz timer; the 30 Hz GraphEditor animation composites cached images; a theme switch is exactly one re-skin pass. All animations use `AnimationDriver` (VBlank-driven, time-bounded). Exactly two exceptions: the AI thinking spinner (in-flight only, region-confined) and the timeline playhead (strip-confined, playing-only). → [`docs/layout_visuals_animation.md §2–3`](../../docs/layout_visuals_animation.md)
- **A cable is not a graph edge** — one drawn wire can be 1 edge, 2 edges + a hidden attenuverter node, or N poly-bus edges. Never identify, hit-test, colour or delete a cable by `AudioProcessorGraph::Connection`; go through `GraphEditor::buildVisibleCables()`, the single enumeration feeding both `paint()` and hit-testing. Wire colour resolves only via `synth::ui::resolveCableColour` — reading a `*Wire` theme token at a paint site breaks user colour overrides. → [`docs/layout_selection_canvas.md §3`](../../docs/layout_selection_canvas.md) · [`docs/theming.md §11`](../../docs/theming.md)
- **Themes don't swap fonts** — all built-ins share Inter + JetBrains Mono; swapping the embedded typeface *family* at runtime corrupts text (JUCE 8 + CoreText). Themes differ by colour/treatment/glow only. → [`docs/theming.md`](../../docs/theming.md)
- **No high-frequency logging** — a global `juce::Logger` (Debug builds) pipes `writeToLog` into a UI-thread console; never add per-sample / per-frame / per-parameter / per-connection logs (one caused a multi-second freeze; guarded by `AIStateMapperTest.PresetLoadDoesNotSpamLogger`). → [`docs/AI_Engine_chat_component.md`](../../docs/AI_Engine_chat_component.md)
- **A module/macro rebuild mid-gesture cancels any live drag, never leaves it waiting on a `mouseUp` that can't arrive** — `ModuleComponent`/`MacroCardComponent::mouseDown` arm `GraphEditor`'s `dragPreviewActive`/`selectionDragActive` and reset them only from their own `mouseUp`; `detachAllModuleComponents()`/`updateComponents()`/`syncMacroCards()` destroying that component first (an async apply, or the dragged node/macro itself vanishing) leaves no component left to deliver one. Call `GraphEditor::cancelLiveDragGestures()` from every such removal site. → [`docs/layout_selection_canvas.md §1.4`](../../docs/layout_selection_canvas.md)
- **A menu whose options a background thread can mutate resolves clicks against a build-time snapshot, never a re-run collector** — the Instrument -> Plugin picker's known-plugin list is mutated by `PluginScanService::runScan` off the message thread, so `TimelinePanelComponent::applyAddTrackMenuChoice` indexes `instrumentPluginMenuSnapshot_` (captured in `buildAddTrackMenu()`), not a fresh `collectInstrumentPluginMenuOptions()` call — a scan finishing mid-menu can otherwise resolve a click against a plugin the menu never showed there. → [`docs/timeline_panel_tracks.md §3`](../../docs/timeline_panel_tracks.md)
- **No file over 1,000 lines** — `GraphEditor.cpp` is this directory's cautionary tale (9,000+ lines before the guard); a class that outgrows one file is split by concern into its own directory (root `CLAUDE.md` § Code structure). `Source/UI/` holds only area directories — `Graph/` (GraphEditor, ModuleComponent, cables, selection, minimap, mod matrix), `Timeline/` (panel, clip lanes, ruler, headers, transport, automation lanes, edit tools), `PianoRoll/`, `Library/` (module library), `Macros/`, `ModuleViews/` (per-module visualizers), `Settings/`, `Assistant/` (AI chat + account), `Chrome/` (toolbar, status bar, welcome, export, shared popups), `Layout/` (layout/focus/animation primitives), `Theme/`; a new file goes into its area, never back into this directory. → [`docs/testing.md`](../../docs/testing.md)
