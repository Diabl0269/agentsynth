# Engine & threading invariants (Source/)

Loaded for any work under `Source/`; the area files (`Modules/`, `Timeline/`, `AI/`, `UI/`, `Plugin/`) add to it. One rule per bullet; mechanism and history live in the linked docs.

- **`HostMode::Hosted` never touches hardware** (no audio device, no MIDI input); drive it only via `prepareForHost`/`processHostBlock`/`releaseFromHost`. → [plugin-layer](../docs/architecture/plugin-layer.md#host-modes-audioenginehostmode)
- **The device callback never allocates, and audio input stays opt-in** (restore requests 0 input channels); Core never touches `ApplicationProperties`. → [audio-engine](../docs/architecture/audio-engine.md#audioengine)
- **A device/sample-rate change goes through `AudioEngine::handleStreamFormatChange` only; a take never spans it** (`AudioTake` freezes its capture rate/bpm/latency at record-on). → [app-wiring](../docs/architecture/app-wiring.md#device--sample-rate-changes)
- **Timeline data crosses threads only via an `EpochExchange`**: open it only in `AudioEngine::renderPass`, never cache a reference across passes; `publishTimeline` (snapshot first, bindings second) after any graph change; edit `TimelineDoc` only through its mutators. → [timeline](../docs/architecture/timeline.md#timelinesnapshot-the-audio-threads-view-of-the-timeline)
- **MIDI Remote never locks, allocates or logs on the MIDI path**: immutable `RemoteMappingSnapshot` by atomic pointer swap, one `AbstractFifo` lane per source, 60 Hz drain timer (no `AsyncUpdater`), apply and feedback on the message thread. → [threading](../docs/control/midi-remote.md#threading-the-mapping-table-crosses-threads) · [apply](../docs/control/midi-remote.md#how-does-a-hardware-value-reach-a-parameter) · [feedback](../docs/control/midi-remote.md#controller-feedback)
- **Every graph change tells `MainComponent` (the `TimelineDoc` owner)**: publish at `timelineChanged`, run the reconcile pass after any add/remove/replace of nodes; a new "replace the graph" path joins the hook table. → [app-wiring](../docs/architecture/app-wiring.md#app-wiring--who-owns-the-timeline-and-every-hook-that-keeps-it-in-step) · [tracks](../docs/timeline/tracks.md#a-binding-is-never-re-established-automatically)
- **Replacing the open document goes through `MainComponent::guardUnsavedChanges(label, proceed)`** (async: never assume `proceed` runs); recompute `isDirty_` from the undo edit serial, never write it directly. → [project-bundle](../docs/architecture/project-bundle.md#dirty-state-and-the-unsaved-changes-guard)
- **Autosave writes `autosave.json`, never `project.json`**, and never fires during a take or bounce (`isRecordingActive()`, `isBounceInProgress_`). → [project-bundle](../docs/architecture/project-bundle.md#autosave-and-crash-recovery)
- **Mixer solo is the engine's render-time per-leg gate**: toggle via `AudioEngine::setChannelStripSoloed`, never fan `setMuted()`; a path that skips `publishTimeline` calls `refreshSoloGate()`. → [mixer](../docs/mixer/mixer.md#solo-is-a-render-time-gate) · [sends](../docs/mixer/sends-and-buses.md) · [audio-engine](../docs/architecture/audio-engine.md#mixer-solo-gate)
- **A send is a strip-owned output leg and a bus is an ordinary `ChannelStripModule`**: no `SendModule`, and a send's target is never stored. → [sends-and-buses](../docs/mixer/sends-and-buses.md)
- **"The channel this node is in" is `synth::nearestChannelMacro`**, never `MacroSet::findByMember`. → [mixer](../docs/mixer/mixer.md)
- **A per-edit pass builds `synth::ConnectionIndex`/`MixerGraphView`/`NodeUuidCache` once**; never `getConnections()` or a uuid scan per item. → [graph-queries](../docs/architecture/graph-queries.md)
- **Undo snapshots come from `synth::GraphSnapshotCache` and are immutable**; a field added to `nodeToJSON` joins the cache check; compare with `synth::sameJson`. → [module-base](../docs/architecture/module-base.md#a-snapshot-costs-what-the-edit-changed-not-the-project)
- **Deleting a track is ONE `recordGraphTimelineAndMacroChange`; "only it used" is `synth::modulesOnlyUsedBy`**, and a new shared singleton joins the keep set. → [tracks](../docs/timeline/tracks.md#row-context-menu)
- **Scrub `ChannelStripModule`'s `"solo"`, `"isBus"`, `"sends"`, `"name"` keys before writing a trusted-apply format**; `extractTrackPreset` is the reference. → [track-presets](../docs/mixer/track-presets.md)
- **Mirror a node's uuid into its processor at every write site** (`ModuleBase::setNodeUuid`); write it once, never clear it. → [module-base](../docs/architecture/module-base.md#node-uuid-mirror-setnodeuuid--getnodeuuid)
- **A bounce suspends external MIDI as well as the device callback**; any new offline-render path pairs `suspendExternalMidi()`/`resumeExternalMidi()`. → [audio-engine](../docs/architecture/audio-engine.md#bounceexport)
- **The input layout store (`AudioInputLayoutStore`) is never pruned except by the user's Forget**: an unplugged interface keeps its pairs and names, and a track's named input resolves through `synth::resolveAudioInput`, never by jack number alone. → [settings](../docs/layout/settings-preferences.md#the-audio-tab) · [tracks](../docs/timeline/tracks.md#audio-tracks)
- **No non-ASCII bytes in a string literal**; use ASCII or `juce::CharPointer_UTF8`/`fromUTF8`. → [ascii-literal-guard](../docs/development/ascii-literal-guard.md)
- **The sound preview is summed after the master and never routed through the graph**: `SoundPreviewPlayer` mixes in `AudioEngine::renderNextBlock` after master mute and before the NaN scrub (standalone and plugin alike), and a bounce or stem export suspends it. → [audio-engine](../docs/architecture/audio-engine.md#sound-preview)
- **No NaN/Inf reaches the device or host**: the scrub in `AudioEngine::renderNextBlock` is the single place, not `MasterModule`. → [audio-engine](../docs/architecture/audio-engine.md#non-finite-sample-scrub)
- **No file over 1,000 lines, no function over 200**; split by concern. → [file-size-guard](../docs/development/file-size-guard.md) · [function-size-guard](../docs/development/function-size-guard.md)
- **`AudioEngine::shutdown()` fires `onBeforeShutdown` first**; any UI owner holding parameter attachments wires it to detach. → [audio-engine](../docs/architecture/audio-engine.md#shutdown-and-onbeforeshutdown)
- **Usage statistics are opt-in and silent when off** (`shareUsageStats`): count on the message thread from user actions only. → [usage-statistics](../docs/development/usage-statistics.md#counting)
- **`Source/Music/` is shared, pure music theory (scales, chords): header-only, `juce_core` only, no Timeline, module or UI types**; code that needs `MidiNote` wraps it from `Timeline/`. → [scale-assist](../docs/timeline/scale-assist.md#the-scale-engine)
- **Test-mode commands run on the message thread; the socket thread does I/O only; activation only behind `AGENTSYNTH_AUTOMATION`**, and an automation launch keeps every user path under its settings directory. → [test-mode](../docs/development/test-mode.md)
