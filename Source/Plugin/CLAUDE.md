# Plugin-layer invariants (Source/Plugin/)

Host-mode rules (`HostMode::Hosted` never touches hardware; the stream-format hook) are in `Source/CLAUDE.md`.

- **A plugin editor never calls `Desktop::setDefaultLookAndFeel`** (process-global in the host); scope with `setLookAndFeel(&processor.getLookAndFeel())`. A detached Timeline/Mixer window (`DetachedPanelWindow`) follows the same rule. → [plugin-layer](../../docs/architecture/plugin-layer.md#who-owns-what) · [panel](../../docs/mixer/panel.md)
- **JUCE is patched, and the patch is load-bearing** for the plugin window's right-click "Add to card" (`cmake/patches/juce-vst3-context-menu.patch`): change the JUCE tag only with a regenerated patch. → [juce-patches](../../docs/development/juce-patches.md) · [plugin-card-layout](../../docs/control/plugin-card-layout.md#add-to-card-from-the-plugin-window)
- **A modulated plugin parameter is written only by `HostedPluginModule::applyModSlots` on the audio thread**; anything else (card knob, plugin window, automation) just sets the parameter, which becomes the resting value next block. Undo of a live plugin restores in place, never reloads. → [plugin-card-layout](../../docs/control/plugin-card-layout.md#modulating-plugin-parameters)
- **A hosted plugin crashes the whole app, so the next launch names it** (running sentinel in `Main.cpp`, macOS crash report parsed by `CrashReportPluginFinder`, "Open without it" skips that plugin for one project load only via `HostedPluginBackend::skipPluginForNextLoad`; its card then offers a Turn on button, `HostedPluginModule::turnBackOn()`, that reloads it keeping the saved state, layout and mod slots). Keep new project-load paths inside a `ScopedClearSkips`, and never persist the bundle path (the name only). → [plugin-layer](../../docs/architecture/plugin-layer.md#when-a-plugin-takes-the-app-down)
