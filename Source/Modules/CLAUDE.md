# Module & channel invariants (Source/Modules/)

The bypass/mute two-branch contract in the root `CLAUDE.md` applies to every `processBlock` here. One rule per bullet; mechanism lives in the linked docs.

- **A second audio leg goes on a new `kRightBase` block, never ch1**; pair legs via `ModuleBase::rightAudioLegChannel()`, pan with `ModuleBase::panGains`, and the Dual I/O toggle is inherited, never registered per module. → [fx-modules](../../docs/modules/fx-modules.md#the-toggle-is-inherited-not-registered)
- **A detector key input is `PortRole::Sidechain`, appended above existing inputs** (`mapStereoKeyInput`), keyed only while `ModuleBase::isSidechainConnected()`. → [fx-modules](../../docs/modules/fx-modules.md#key-inputs-sidechain)
- **A module's channel count is fixed for its lifetime**: declare the maximum, vary only the visible port count, drop routings on hidden jacks; an oversize hosted plugin is refused. → [module-base](../../docs/architecture/module-base.md#logical-port-api) · [modules](../../docs/modules/modules.md#hosted-plugin-module-third-party-vst3--au-hidden)
- **A Channel Strip's input shape is written once; the solo gate applies in both bypass and normal branches, per leg**, and every branch clears inactive send channels (8-15). → [modules](../../docs/modules/modules.md#channel-strip-module-mixer-channel-hidden) · [sends-and-buses](../../docs/mixer/sends-and-buses.md)
- **A meter reader takes its own `PeakMeterLatch` slot**; a new consumer gets a new `MeterReader` enumerator. → [meters](../../docs/mixer/meters.md#a-per-reader-peak-latch)
- **Every Wavetable warp mode proves it doesn't alias**: `warpRateFactor` or `warpNeedsOversampling`, plus `WavetableWarpAliasTest`/`WavetableWarpBoundsTest` entries. → [wavetable](../../docs/modules/wavetable.md#warp)
- **A non-gain parameter must not add gain**: `ModuleGainAudit` fails above +6 dB; no bumped ceilings. → [gain-staging](../../docs/development/gain-staging.md) · [fx-modules](../../docs/modules/fx-modules.md#ring-modulator-module)
- **A message-thread lookup table crosses to the audio thread** through `LockFreeHandoff` (an immutable heap table in an atomic slot, retired on the message thread), or as a fixed array under a SpinLock try-lock; never allocate or free on the audio thread. → [lfo](../../docs/modules/lfo.md) · [custom-filter](../../docs/modules/custom-filter.md#shape-handoff)
- **Normalling is render-time, never an edge**: `AudioEngine::refreshNormalling` and `applyLeftRightNormalling()`; opt in with `hasStereoAudioInputPair()`, never by channel shape. → [audio-engine](../../docs/architecture/audio-engine.md#normalling-fro324) · [fx-modules](../../docs/modules/fx-modules.md#right-borrows-left-while-unpatched-fro324)
- **`ModuleBase::processBlock` is `final`; override `processModuleBlock`** (stereo-pair down-mix happens before it). → [audio-engine](../../docs/architecture/audio-engine.md#stereo-down-mix-fro326)
- **A module storing a file path in extra state registers it in `synth::ModuleFileRefs`** (keys in `ModuleFileStateKeys.h`); keep it absolute in memory. → [project-bundle](../../docs/architecture/project-bundle.md#projectbundle-agsproj) · [app-wiring](../../docs/architecture/app-wiring.md#collect--archive)
- **The per-sample loop does only per-sample work**: `VisualBuffer::pushBlock`/`pushConstant`, no per-block allocation, block constants hoisted. → [audio-engine](../../docs/architecture/audio-engine.md#measuring-render-cost)
- **"Is a CV input patched?" probes scan the whole block, never the first 64 samples.** → [modulation](../../docs/modules/modulation.md#automation-writes-the-base-value-cv-stacks-on-top)
- **A module with a dry audio path calls `prepareOutputLevel()` or `prepareOutputStage()` in `prepareToPlay`**, so the base can crossfade bypass without allocating; the two bypass/mute branches stay as they are. → [module-base](../../docs/architecture/module-base.md#the-transition-around-the-two-branches)
