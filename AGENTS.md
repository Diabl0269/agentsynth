# AGENTS.md

Guidance for coding agents in this repository lives in [`CLAUDE.md`](CLAUDE.md) — commands,
conventions, and the map of which area `CLAUDE.md` guards which topics. The per-directory
`CLAUDE.md` files (`Source/`, `Source/Modules/`, `Source/Timeline/`, `Source/AI/`, `Source/UI/`,
`Source/Plugin/`, `.github/`) hold the full invariants for that area, and [`docs/README.md`](docs/README.md)
maps the mechanism/history docs behind them.

This file is a pointer, not a copy — it is kept in sync manually and can drift; treat `CLAUDE.md`
and the area files as the source of truth.
