# Agents & AI Integration

This project integrates local AI capabilities for sound design assistance.

## Supported Providers
- **Ollama**: Configurable via the Settings → AI tab.

## AI Features
- **Natural Language Patching**: Text-to-patch generation using local LLMs.
- **Experimental Patching**: AI-assisted patching workflow managed by `AIIntegrationService`.
