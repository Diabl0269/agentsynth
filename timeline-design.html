Gravisynth Timeline Design Approaches

Option 1: Global Timeline (DAW-style)
[ Master HUD: Play / Pause / Stop / Loop ]
------------------------------------------
[ Arrangement View (Clips / Automation) ]
------------------------------------------
[ Graph Editor (Modular Patch) ]

Workflow: Dedicated, non-modular arrangement view. Clear master control, standard DAW UX.

Option 2: Timeline Module (Node-based)
[ Graph Editor ]
[ Timeline Node A ] --(MIDI)--> [ Filter ]
[ Timeline Node B ] --(MIDI)--> [ Osc ]

Workflow: Patchable timeline nodes. Highly flexible routing, but lacks unified transport control.

Recommendation: Hybrid (Timeline Nodes + Master HUD)
[ Global Transport Sync HUD ]
-----------------------------
[ Graph Editor ]
[ Timeline Node ] --MIDI--> [ Synth ]

Workflow: Timeline Nodes perform the data orchestration, Master HUD manages global transport. Flexibility of modular + sync of a DAW.
